## 📖 About This Repository
 
This repository contains all hands-on labs, portfolio activities, and projects completed during the **Google Cybersecurity Professional Certificate** — an 8-course program covering the full cybersecurity analyst skill set: security frameworks, network defense, Linux and SQL, asset and threat management, detection and response, and Python automation.
 
Each project folder contains a `README.md` with scenario context, tasks completed, tools and concepts applied, key observations, and what I learned. The work reflects real analyst workflows: writing security reports, analyzing network traffic, managing Linux permissions, querying databases, triaging alerts, and building Python automation scripts.
